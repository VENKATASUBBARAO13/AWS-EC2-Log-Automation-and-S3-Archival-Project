# Amazon S3 Log Archive

Create a dedicated private S3 bucket to store the log archives produced by the Lambda function.

## Recommended settings

- Keep **Block Public Access** enabled.
- Enable **Server-side encryption**.
- Use a dedicated prefix such as `ec2-logs/`.
- Enable versioning if the project requires object-history protection.
- Configure lifecycle rules if long-term archives are retained.

## Example object layout

```text
s3://<bucket-name>/
└── ec2-logs/
    └── YYYY/MM/DD/
        └── HHMMSS-cloudwatch-logs.json
```

The exact key structure is generated by the Lambda example in `lambda/log_automation.py`.

## Security

Do not make the bucket public. Grant the Lambda execution role only the S3 actions and prefix it needs.
